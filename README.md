# 0916

A modern, responsive personal dashboard featuring a real-time precision clock, dynamic greeting, customizable user profile, and custom themes.

## Features
- **Live Precision Clock**: Synchronized digital clock with 12h/24h toggle and animated analog visualizer.
- **Dynamic Greeting**: Automatically adjusts greeting based on the time of day.
- **Personal Profile**: Customizable user name with local storage persistence.
- **Theme & Accent Customization**: Dark/Light mode and multiple neon accent palettes.
- **Productivity Extras**: Built-in focus stopwatch and one-click timestamp copy.

## Quick Start
Open `index.html` in any web browser or serve with Python:
```bash
python -m http.server 8085
```
